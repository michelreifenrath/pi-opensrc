# Security Policy

## Supported Versions

Security fixes are published for the latest npm release of `pi-opensrc`.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository when available:

<https://github.com/michelreifenrath/pi-opensrc/security/advisories/new>

If that is unavailable, open a public issue that only asks for a private contact channel and does not include exploit details.

## Scope

This package is an unofficial wrapper for `vercel-labs/opensrc`. Reports about the upstream `opensrc` CLI or skill should also be reported to the upstream project when applicable.
